# Dataset

The IEEE-CIS Fraud Detection dataset is **not included** in this repository.
It is competition data: use is permitted, redistribution is not.

Download it from:
https://www.kaggle.com/c/ieee-fraud-detection

Place these two files in this folder:

```
ieee-fraud-detection/
  train_transaction.csv
  train_identity.csv
```

Then run the notebook in cell order. Everything else in this folder
(`merged_raw.pkl`, the partition pickles, and the serialised corpora
`llm_training_data.json`, `llm_train_formatted.json`, `llm_val_formatted.json`)
is generated by the notebook and is deliberately not committed.
