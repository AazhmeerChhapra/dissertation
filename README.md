## What this artefact is

A two-stage pipeline that generates natural language explanations of fraud
decisions which are grounded in a classifier's own feature attributions, and an
evaluation of those explanations against criteria derived from ISO/IEC 42001.

A gradient-boosted classifier makes the fraud decision. SHAP attributions from
that classifier are supplied in the prompt, and a fine-tuned language model
verbalises them. The model never infers evidence; it restates evidence it has
been given.

## Pipeline

| Phase | Cells | What happens |
|---|---|---|
| 1. Baseline classifier | #3 to #31 | Join the transaction and identity tables, split chronologically at the 80th percentile to prevent temporal leakage, tune with a 30-trial Optuna study maximising AUPRC |
| 2. SHAP attribution | #32 to #44 | TreeExplainer over the full 118,108-row test partition; assign an interpretability tier to each fraud transaction |
| 3. Serialisation | #45 to #59 | Convert transactions and their attributions into prompt-target pairs; build a balanced corpus of 8,128 examples |
| 4. QLoRA fine-tuning | #60 to #74 | Mistral-7B-Instruct-v0.2 in 4-bit NF4 with rank-32 adapters; loss masked by position rather than token identity |
| 5. Evaluation | #75 to #107 | Faithfulness measurement, counterfactual perturbation test, ISO 42001 rubric scoring |

## To reproduce

1. Download the dataset into `ieee-fraud-detection/`
2. Create a Hugging Face account, accept the Mistral-7B-Instruct-v0.2 licence,
   and authenticate with `huggingface-cli login`
3. `pip install -r requirements.txt`
4. Run the notebook in cell order

Fine-tuning took approximately 8 hours (1,371 steps over three epochs) on an
NVIDIA GeForce RTX 5060 laptop GPU with 8.5 GB of VRAM. Several cells reload
cached artefacts from disk, so the later phases can be run without repeating
the earlier ones.

## Notes

The interpretability ceiling reported in Section 4.3 is a property of the
dataset, not of the method: only twelve of the 431 model features carry
directly human-readable meaning, and in 19.0% of fraud transactions none of the
top five SHAP drivers is interpretable.

Cells #103 to #106 are exploratory. With a single fabrication case across 200
explanations these breakdowns carry no statistical weight, and they are not
reported in the dissertation (Section 5.8).
